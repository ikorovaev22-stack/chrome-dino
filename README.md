# Дино-забег

Цветной пиксельный забег динозаврика по пяти мирам, по мотивам офлайн-игры
Google Chrome. Плюс точная копия оригинальной игры из Chrome.

Играть: https://ikorovaev22-stack.github.io/chrome-dino/
Классическая версия из Chrome: https://ikorovaev22-stack.github.io/chrome-dino/classic.html

Основа игры не переписана заново: это оригинальный код из
[Chromium](https://source.chromium.org/chromium/chromium/src/+/main:components/neterror/resources/)
(`components/neterror/resources`). Поэтому прыжок, скорость, кактусы,
птеродактили, смена дня и ночи и экран Game Over работают так же, как в
Chrome. Всё остальное достроено поверх него.

## Что в игре

**Интерфейс внутри игры.** Страница — просто тёмная рамка вокруг игры, а всё
остальное игра рисует сама на холсте поверх игры Chrome: титульное меню,
счётчики во время забега, паузу, итоги забега, магазин улучшений, скины и
справку. Меню управляются стрелками, Enter и мышью или касанием.

**Цвет.** Спрайты Chrome перекрашены с тенями и тёмной обводкой: динозавр,
кактусы, птеродактиль, облака, цифры, кнопка рестарта. За ними небо с
градиентом, солнце, слои параллакс-фона, земля и почва под дорожкой. Ночью
небо плавно темнеет, появляются луна и звёзды.

**Ночное освещение.** Ночью сцену накрывает темнота, а вокруг динозавра,
солнца, монет, бонусов, лавы, светлячков и искр остаются мягкие пятна света
с цветным ореолом. В вулкане всегда немного темно, чтобы светилась лава.

**Уровни-миры.** По мере забега мир меняется, и каждый раз выезжает баннер
«Уровень N»:

| Уровень | Мир | С какого счёта | Особенности |
|---|---|---|---|
| 1 | Пустыня | 0 | дюны, камни, перекати-поле, песчаные бури |
| 2 | Каньон | 500 | закат, плато, валуны, птицы |
| 3 | Лес | 1100 | ёлки, брёвна, пни, дождь, листопад, светлячки |
| 4 | Снежные горы | 1800 | снеговики, катящиеся снежки, ледяные глыбы, метель |
| 5 | Вулкан | 2600 | лавовые гейзеры, дым и искры, тёмные облака |

После вулкана миры повторяются каждые 900 очков. Скорость растёт плавнее,
чем в Chrome, и упирается в потолок пониже.
Цвет кактусов тоже зависит от мира: заснеженные в горах, обугленные у вулкана.

**Сердца.** Забег начинается с трёх сердец. Столкновение отнимает одно и
даёт короткую неуязвимость, игра заканчивается, когда сердца кончаются.

**Монеты и бонусы.** Монеты висят дугами над препятствиями и рядами в
воздухе, каждая даёт +10 очков. Монеты, собранные подряд без долгих пауз,
складываются в комбо: каждые три монеты увеличивают множитель, до ×5.
Бонусы выпадают в цветной рамке:

| Бонус | Действие |
|---|---|
| Щит | Спасает от одного столкновения |
| Двойной прыжок | 10 секунд можно подпрыгнуть ещё раз в воздухе |
| Магнит | 10 секунд монеты сами летят к динозавру |
| Звезда | 6 секунд неуязвимости с радужным шлейфом, препятствия разлетаются (+25) |
| Замедление | 6 секунд всё движется медленнее |
| Сердце | Возвращает одно потерянное сердце |

**Улучшения.** Монеты копятся от забега к забегу. В магазине за них
покупаются постоянные улучшения: запас сердец (до пяти), сильный магнит,
яркая звезда (бонусы действуют дольше), щит на старте каждого забега и
удача (бонусы выпадают чаще).

**Скины.** За монеты открываются и новые цвета динозавра: зелёный и
«хромовый» доступны сразу, огненный — за 150 монет, ледяной — за 300,
фиолетовый — за 500, золотой — за 1000.

**Анимации.** Пыль из-под лап и при приземлении, тряска и вспышка экрана при
столкновении, птицы и дым вулканов на фоне, погода, мерцающие бонусы, баннер
нового уровня.

## Управление

**Пробел / ↑** — прыжок, **↓** — пригнуться (или ускорить падение в
прыжке), **Esc / P** — пауза, **F** — во весь экран. В меню — стрелки,
**Enter** и **Esc** (назад). На телефоне — касание экрана и кнопка паузы.

## На iPhone

Откройте https://ikorovaev22-stack.github.io/chrome-dino/ в Safari, нажмите
«Поделиться» → **«На экран Домой»** → «Добавить». Появится иконка
«Дино-забег», и игра будет открываться как приложение: на весь экран, без
панелей Safari, в обход выреза и Dynamic Island. Лучше держать телефон
горизонтально — так экран больше. После первого запуска игра сохраняется на
телефоне и работает без интернета; новые версии подтягиваются сами, когда
сеть есть.

Звук включается после первого касания; если на iPhone включён беззвучный
режим, звука не будет. Звуки из оригинальной игры Chrome на iOS выключены
самим Chrome, звучат только новые эффекты.

На Android то же самое: в Chrome «Добавить на главный экран».

## Классическая версия

`classic.html` — копия страницы «Нет подключения к интернету» из Chrome с
оригинальной игрой. Она без изменений: чёрно-белая, со светлой и тёмной темой,
по-русски или по-английски по языку браузера (или `?lang=ru` / `?lang=en`).
Старые ссылки с `?classic` и `#classic` ведут туда же. Рекорды двух версий
хранятся отдельно.

## Запуск

Нужен [Node.js](https://nodejs.org/) 20.19+ или 22.12+.

```bash
npm install
npm run dev      # локальный сервер разработки
npm run build    # сборка в папку dist/
npm run preview  # просмотр собранной версии
```

Каждый пуш в `main` собирает игру и публикует её на GitHub Pages
(`.github/workflows/deploy.yml`).

## Устройство проекта

```
index.html, src/game_main.ts   страница цветной игры, раскладка слоёв
src/game.css                   её стили
src/service_worker.js          офлайн-режим (сборка превращает его в sw.js
                               со списком всех файлов игры)
public/                        манифест и иконки для экрана «Домой»
src/ui/                        интерфейс внутри игры:
  app.ts                         сцена, освещение, погода, HUD и все меню
  draw.ts                        панели, кнопки, пиксельный шрифт
classic.html, src/classic_main.ts
                               копия страницы ошибки Chrome
src/host.ts                    хранение рекорда (в Chrome — профиль браузера)
src/dino_game/                 код игры из Chromium + точки подключения расширений
src/extras/                    всё новое:
  biomes.ts                      миры и уровни
  recolor.ts, theme.ts           перекраска спрайтов Chrome по мирам и скинам
  scenery.ts                     небо, солнце, параллакс, земля, ночь, птицы, дым
  extras.ts                      сердца, монеты и комбо, бонусы, эффекты
  obstacles.ts                   новые препятствия
  lighting.ts                    ночное освещение
  upgrades.ts                    улучшения из магазина
  weather.ts                     погода
  art.ts, pixel_art.ts           пиксельная графика
  skins.ts, sfx.ts, events.ts    скины, звуки, события для страницы
src/neterror.ts, src/*.css     страница ошибки и стили из Chromium
src/chrome_resources/js/       хелперы WebUI из Chromium (assert, loadTimeData)
src/images/, src/sounds/       оригинальные спрайты и звуки
```

Сцена собрана из слоёв друг над другом: холст сцены (`#scene`), игра Chrome
(`#stage`), два слоя освещения (`#shade` и `#glow`) и холст интерфейса
(`#fx`) с погодой, HUD и меню. Холсты сцены и интерфейса рисуются в полном
разрешении экрана, чтобы пиксель-арт оставался чётким.

Освещение — это только мягкие градиенты, поэтому его слои рисуются в
игровых пикселях (до 600×240) и растягиваются до размера экрана средствами
CSS. Масштабирует их композитор браузера на GPU, так что ночь стоит почти
столько же, сколько день, даже на 4K-экранах. Цветные ореолы складываются со
сценой через `mix-blend-mode: plus-lighter` (в старых браузерах — `screen`).
Днём оба слоя скрыты.

Импорты вида `chrome://resources/...` перенаправляются на локальные файлы в
`vite.config.ts` и `tsconfig.json`.

Изменения в исходниках Chromium помечены комментариями:

- `chrome-dino extras` — точки, где игра вызывает расширения
  (`offline.ts`, `horizon.ts`, `obstacle.ts`, `trex.ts`). На классической
  странице расширения выключены, и ни одна из этих точек не срабатывает.
  Остальные файлы `src/dino_game/` совпадают с Chromium байт в байт;
- `chrome-dino` в `neterror.ts`: страница всегда рисуется в режиме основного
  окна (иначе внутри iframe игра бы не показывалась), а условные блоки
  `<if expr>` препроцессора grit заменены проверками во время выполнения;
- `neterror.css`: блоки `<if expr>` раскрыты для десктопной сборки, удалены
  правила для картинок других страниц ошибок, которых здесь нет.
