# Chrome Dino

Офлайн-игра с динозавриком из Google Chrome, та самая, что появляется на
странице «Нет подключения к интернету», плюс расширенная версия с монетами,
бонусами, новыми препятствиями и погодой.

Основа игры не переписана заново: это оригинальный код из
[Chromium](https://source.chromium.org/chromium/chromium/src/+/main:components/neterror/resources/)
(`components/neterror/resources`) с его спрайтами, звуками, CSS и переводами.
Поэтому физика прыжка, скорость, кактусы, птеродактили, ночной режим, звуки и
экран Game Over работают так же, как в Chrome.

## Два режима

- **Расширенный** (по умолчанию): всё из Chrome плюс нововведения ниже.
- **Классический**: точная копия игры из Chrome. Откройте страницу с
  `?classic` в адресе (или `#classic`, если открываете файл с диска).

Рекорды у режимов хранятся раздельно.

## Что добавлено в расширенном режиме

**Монеты.** Висят дугами над кактусами и рядами в воздухе и у земли. Каждая
монета даёт +10 очков, счётчик монет за забег — в левом верхнем углу.

**Бонусы** выпадают в рамке примерно раз в 12–20 секунд, иногда у земли,
иногда так, что за ними нужно прыгнуть. Активные бонусы и оставшееся время
видны под счётчиком монет; перед окончанием значок мигает.

| Значок | Бонус | Действие |
|---|---|---|
| щит | Щит | Спасает от одного столкновения, препятствие разбивается |
| двойная стрелка | Двойной прыжок | 10 секунд можно подпрыгнуть ещё раз в воздухе |
| подкова | Магнит | 10 секунд монеты сами летят к динозавру |
| звезда | Звезда | 6 секунд динозавр неуязвим и сносит препятствия, +25 очков за каждое |
| песочные часы | Замедление | 6 секунд всё движется медленнее |

**Новые препятствия.** Камни и перекати-поле, которое катится чуть быстрее
земли и подпрыгивает, так что прыжок нужно рассчитать.

**Погода.** По ходу забега ясное небо сменяется дождём, снегом или песчаной
бурей.

Вся новая графика нарисована в стиле оригинальных спрайтов (те же цвета и
белая обводка), поэтому в ночном режиме и в тёмной теме она выглядит так же
естественно.

## Общие возможности

- Страница ошибки `DNS_PROBE_FINISHED_NO_INTERNET`, как в Chrome: светлая и
  тёмная тема (по настройкам системы), русский и английский языки (по языку
  браузера или параметром `?lang=ru` / `?lang=en`)
- Управление: **Пробел / ↑** — прыжок, **↓** — пригнуться (или ускорить
  падение в прыжке), **Enter** — начать заново; на телефоне — касание
- Рекорд (`HI`) сохраняется между запусками; двойное нажатие на рекорд
  после проигрыша сбрасывает его, как в Chrome
- Режим для незрячих со звуковыми подсказками и переключателем
  «Запустить медленнее»: кликните по динозаврику (или выберите его Tab'ом)
  и нажмите Пробел
- Режим `chrome://dino`: параметр `?arcade` растягивает игру на весь экран
  и включает поддержку геймпада

## Запуск

Нужен [Node.js](https://nodejs.org/) 20.19+ или 22.12+.

```bash
npm install
npm run dev      # локальный сервер разработки
npm run build    # сборка в папку dist/
npm run preview  # просмотр собранной версии
```

## Публикация на GitHub Pages

В репозитории уже есть workflow `.github/workflows/deploy.yml`, который
собирает игру и публикует её при каждом пуше в `main`. Его нужно один раз
включить: **Settings → Pages → Build and deployment → Source: GitHub Actions**,
после этого перезапустите workflow во вкладке **Actions**. Игра будет доступна
по адресу `https://<ваш-логин>.github.io/chrome-dino/`.

## Устройство проекта

```
index.html                     аналог neterror.html из Chromium
src/main.ts                    точка входа: тексты и «контроллер» браузера
src/strings.ts                 русские и английские строки из Chromium
src/neterror.ts                логика страницы ошибки из Chromium
src/dino_game/                 код игры из Chromium (+ точки подключения расширений)
src/extras/                    расширенный режим: монеты, бонусы, погода,
                               новые препятствия, графика и звуки
src/chrome_resources/js/       хелперы WebUI из Chromium (assert, loadTimeData)
src/*.css                      стили страницы ошибки из Chromium
src/images/, src/sounds/       оригинальные спрайты и звуки
```

Импорты вида `chrome://resources/...` перенаправляются на локальные файлы в
`vite.config.ts` и `tsconfig.json`.

Отличия от исходников Chromium сведены к минимуму и помечены комментариями:

- `chrome-dino extras` — точки, где оригинальная игра вызывает расширенный
  режим (`offline.ts`, `horizon.ts`, `obstacle.ts`, `trex.ts`). В
  классическом режиме ни одна из них не срабатывает. Остальные файлы
  `src/dino_game/` совпадают с Chromium байт в байт;
- `chrome-dino` в `neterror.ts`: страница всегда рисуется в режиме основного
  окна (иначе внутри iframe игра бы не показывалась), а условные блоки
  `<if expr>` препроцессора grit заменены проверками во время выполнения;
- `neterror.css`: блоки `<if expr>` раскрыты для десктопной сборки, удалены
  правила для картинок других страниц ошибок, которых здесь нет;
- рекорд, который Chrome хранит в профиле, здесь хранится в `localStorage`
  (`src/main.ts`).
