# Chrome Dino

Точная копия офлайн-игры с динозавриком из Google Chrome — той самой, что
появляется на странице «Нет подключения к интернету».

Это не переписанный «по мотивам» клон: здесь использован оригинальный код игры
из [Chromium](https://source.chromium.org/chromium/chromium/src/+/main:components/neterror/resources/)
(`components/neterror/resources`) вместе с его спрайтами, звуками, CSS и
переводами. Поэтому физика прыжка, скорость, препятствия, птеродактили, ночной
режим, звуки, счёт и экран Game Over работают точно так же, как в Chrome.

## Возможности

- Страница ошибки `DNS_PROBE_FINISHED_NO_INTERNET` один в один, как в Chrome:
  светлая и тёмная тема (по настройкам системы), русский и английский языки
  (по языку браузера или параметром `?lang=ru` / `?lang=en`)
- Управление: **Пробел / ↑** — прыжок, **↓** — пригнуться (или ускорить
  падение в прыжке), **Enter** — начать заново; на телефоне — касание
- Рекорд (`HI`) сохраняется между запусками; двойное нажатие на рекорд
  после проигрыша сбрасывает его, как в Chrome
- Режим для незрячих со звуковыми подсказками и переключателем
  «Запустить медленнее»: кликните по динозаврику (или выберите его Tab'ом)
  и нажмите Пробел
- Режим `chrome://dino`: откройте страницу с параметром `?arcade` — игра
  растянется на весь экран
- Поддержка геймпада в режиме `?arcade`

## Запуск

Нужен [Node.js](https://nodejs.org/) 20.19+ или 22.12+.

```bash
npm install
npm run dev      # локальный сервер разработки
npm run build    # сборка в папку dist/
npm run preview  # просмотр собранной версии
```

## Публикация на GitHub Pages

В репозитории уже есть workflow `.github/workflows/deploy.yml`, который
собирает игру и публикует её при каждом пуше в `main`. Его нужно один раз
включить: **Settings → Pages → Build and deployment → Source: GitHub Actions**,
после этого перезапустите workflow во вкладке **Actions**. Игра будет доступна
по адресу `https://<ваш-логин>.github.io/chrome-dino/`.

## Устройство проекта

```
index.html                     аналог neterror.html из Chromium
src/main.ts                    точка входа: тексты и «контроллер» браузера
src/strings.ts                 русские и английские строки из Chromium
src/neterror.ts                оригинальная логика страницы ошибки
src/dino_game/                 оригинальный код игры (без изменений)
src/chrome_resources/js/       хелперы WebUI из Chromium (assert, loadTimeData)
src/*.css                      оригинальные стили страницы ошибки
src/images/, src/sounds/       оригинальные спрайты и звуки
```

Файлы в `src/dino_game/` совпадают с Chromium байт в байт, поэтому их можно
обновлять простым копированием из исходников Chrome. Импорты вида
`chrome://resources/...` перенаправляются на локальные файлы в
`vite.config.ts` и `tsconfig.json`.

Отличия от исходников Chromium сведены к минимуму и помечены комментарием
`chrome-dino`:

- `neterror.ts`: страница всегда рисуется в режиме основного окна (иначе
  внутри iframe игра бы не показывалась), а условные блоки `<if expr>`
  препроцессора grit заменены проверками во время выполнения;
- `neterror.css`: блоки `<if expr>` раскрыты для десктопной сборки, удалены
  правила для картинок других страниц ошибок, которых здесь нет;
- рекорд, который Chrome хранит в профиле, здесь хранится в `localStorage`
  (`src/main.ts`).
