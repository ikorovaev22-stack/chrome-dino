# Дино-забег

Цветной пиксельный забег динозаврика по пяти мирам, по мотивам офлайн-игры
Google Chrome. Плюс точная копия оригинальной игры из Chrome.

Играть: https://ikorovaev22-stack.github.io/chrome-dino/
Классическая версия из Chrome: https://ikorovaev22-stack.github.io/chrome-dino/classic.html

Основа игры не переписана заново: это оригинальный код из
[Chromium](https://source.chromium.org/chromium/chromium/src/+/main:components/neterror/resources/)
(`components/neterror/resources`). Поэтому прыжок, скорость, кактусы,
птеродактили, смена дня и ночи и экран Game Over работают так же, как в
Chrome. Всё остальное достроено поверх него.

## Что в игре

**Цвет.** Спрайты Chrome перекрашены с тенями и тёмной обводкой: динозавр,
кактусы, птеродактиль, облака, цифры, кнопка рестарта. За ними небо с
градиентом, солнце, два слоя параллакс-фона и земля. Ночью небо плавно
темнеет, появляются луна и звёзды.

**Уровни-миры.** По мере забега мир меняется, и каждый раз выезжает баннер
«Уровень N»:

| Уровень | Мир | С какого счёта | Особенности |
|---|---|---|---|
| 1 | Пустыня | 0 | дюны, камни, перекати-поле, песчаные бури |
| 2 | Каньон | 400 | закат, плато, валуны, птицы |
| 3 | Лес | 900 | ёлки, брёвна, пни, дождь и листопад |
| 4 | Снежные горы | 1500 | снеговики, катящиеся снежки, ледяные глыбы, метель |
| 5 | Вулкан | 2200 | лавовые гейзеры, дым и искры, тёмные облака |

После вулкана миры повторяются каждые 800 очков, а скорость продолжает расти.
Цвет кактусов тоже зависит от мира: заснеженные в горах, обугленные у вулкана.

**Монеты и бонусы.** Монеты висят дугами над препятствиями и рядами в
воздухе, каждая даёт +10 очков. Бонусы выпадают в цветной рамке:

| Бонус | Действие |
|---|---|
| Щит | Спасает от одного столкновения |
| Двойной прыжок | 10 секунд можно подпрыгнуть ещё раз в воздухе |
| Магнит | 10 секунд монеты сами летят к динозавру |
| Звезда | 6 секунд неуязвимости с радужным шлейфом, препятствия разлетаются (+25) |
| Замедление | 6 секунд всё движется медленнее |

**Скины.** Монеты копятся от забега к забегу и открывают новые цвета
динозавра: зелёный и «хромовый» доступны сразу, огненный — за 100 монет,
ледяной — за 250, фиолетовый — за 500, золотой — за 1000.

**Анимации.** Пыль из-под лап и при приземлении, тряска и вспышка экрана при
столкновении, птицы и дым вулканов на фоне, погода, мерцающие бонусы, баннер
нового уровня.

## Управление

**Пробел / ↑** — прыжок, **↓** — пригнуться (или ускорить падение в
прыжке), **Enter** — начать заново. На телефоне — касание экрана.

## Классическая версия

`classic.html` — копия страницы «Нет подключения к интернету» из Chrome с
оригинальной игрой. Она без изменений: чёрно-белая, со светлой и тёмной темой,
по-русски или по-английски по языку браузера (или `?lang=ru` / `?lang=en`).
Старые ссылки с `?classic` и `#classic` ведут туда же. Рекорды двух версий
хранятся отдельно.

## Запуск

Нужен [Node.js](https://nodejs.org/) 20.19+ или 22.12+.

```bash
npm install
npm run dev      # локальный сервер разработки
npm run build    # сборка в папку dist/
npm run preview  # просмотр собранной версии
```

Каждый пуш в `main` собирает игру и публикует её на GitHub Pages
(`.github/workflows/deploy.yml`).

## Устройство проекта

```
index.html, src/game_main.ts   страница цветной игры
src/game.css                   её стили
classic.html, src/classic_main.ts
                               копия страницы ошибки Chrome
src/host.ts                    хранение рекорда (в Chrome — профиль браузера)
src/dino_game/                 код игры из Chromium + точки подключения расширений
src/extras/                    всё новое:
  biomes.ts                      миры и уровни
  recolor.ts, theme.ts           перекраска спрайтов Chrome по мирам и скинам
  scenery.ts                     небо, солнце, параллакс, земля, ночь, птицы, дым
  extras.ts                      монеты, бонусы, эффекты, баннер, счётчики
  obstacles.ts                   новые препятствия
  weather.ts                     погода
  art.ts, pixel_art.ts           пиксельная графика
  skins.ts, sfx.ts, events.ts    скины, звуки, события для страницы
src/neterror.ts, src/*.css     страница ошибки и стили из Chromium
src/chrome_resources/js/       хелперы WebUI из Chromium (assert, loadTimeData)
src/images/, src/sounds/       оригинальные спрайты и звуки
```

Импорты вида `chrome://resources/...` перенаправляются на локальные файлы в
`vite.config.ts` и `tsconfig.json`.

Изменения в исходниках Chromium помечены комментариями:

- `chrome-dino extras` — точки, где игра вызывает расширения
  (`offline.ts`, `horizon.ts`, `obstacle.ts`, `trex.ts`). На классической
  странице расширения выключены, и ни одна из этих точек не срабатывает.
  Остальные файлы `src/dino_game/` совпадают с Chromium байт в байт;
- `chrome-dino` в `neterror.ts`: страница всегда рисуется в режиме основного
  окна (иначе внутри iframe игра бы не показывалась), а условные блоки
  `<if expr>` препроцессора grit заменены проверками во время выполнения;
- `neterror.css`: блоки `<if expr>` раскрыты для десктопной сборки, удалены
  правила для картинок других страниц ошибок, которых здесь нет.
